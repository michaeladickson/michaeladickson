Finance and operations leader. Seven years at Xometry from Series A through IPO, then CFO of a $135M PE-backed company. I now own and operate six Crumbl Cookies franchise stores in Kentucky and Ohio.

## What I build

I built the operating platform for the stores myself, with AI development tools. The code is private. It covers:

- Labor, production and cash forecasting
- Inventory counts and ordering
- KPI and incentive scorecards for store managers
- A data warehouse joining POS, payroll, accounting and banking data
- Scheduled agents for email triage, weekly briefs and data-quality checks

Built with Python, FastAPI and PostgreSQL on Google Cloud Run, with a React and TypeScript front end, using Claude Code and Gemini.
